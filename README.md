# 메디패스 응급실 연결

환자 상태에 맞는 응급실을 찾아 주는 단일 HTML 웹앱입니다.

- **일반인 문진**: 눈으로 보고 물어서 알 수 있는 항목으로 긴급도(지금 119 / 지금 응급실 / 오늘 진료)와 필요한 병원 자원(CT·MRI·혈관촬영·중증질환 수용 등)을 판단합니다. 근거: BE-FAST, G-FAST, 2021 AHA/ACC 흉통 지침, Canadian CT Head Rule, PECARN, NICE 발열 신호등, UK Sepsis Trust, 2018 ESC 실신 지침, WAO 아나필락시스, ABA 화상 기준, Ottawa SAH Rule, 2021 현장 외상분류.
- **병원 매칭**: 국립중앙의료원 응급의료정보조회서비스(공공데이터포털) 실시간 병상·장비·중증질환 수용 정보로 필수 자원이 없는 병원을 거르고, 도착 시간·혼잡도·병원 메시지로 순위를 매깁니다.
- **자동심장충격기(AED)**: 심정지가 의심되면 국립중앙의료원 AED 정보조회 서비스로 가장 가까운 AED 3곳(거리·걸어서 걸리는 시간·설치 위치·관리자 연락처)을 보여 주고 지도에 표시합니다.
- **119 구급대 / 응급실 현황** 탭 포함.

## 사용법
`index.html`을 브라우저로 열거나 GitHub Pages(Settings → Pages → Branch: main)로 배포합니다.

## 주의
- 진단 도구가 아닙니다. 위급하면 119에 전화하세요.
- 일반인 문진의 정확도는 검증되지 않았으며, 애매하면 더 위급한 쪽으로 안내하도록 설계했습니다.

## 자체 길찾기 서버 (OSRM)
기본은 공개 OSRM 서버를 씁니다. 직접 운영하려면 [osrm/README.md](osrm/README.md)를 보세요 (Docker로 한국 지도 OSRM 서버 실행, 앱 설정에서 주소 입력, 응답이 없으면 공개 서버로 자동 전환).
